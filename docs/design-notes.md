# 設計筆記

這份筆記記錄這個網站的幾個設計取捨，給之後想修改它的人（包括未來的我）看。

## 先回答「我這裡現在怎麼樣」

大多數人打開空品網站，是為了知道自己常去的地方現在能不能出門運動。所以首屏只放一件事：所選測站的 AQI，用依等級著色的大方塊顯示，旁邊是站名、類別、資料時間，右邊是給一般民眾和敏感族群的建議。全台排行、地圖和縣市統計都放在這張卡之後。

- 測站用單一搜尋框選擇（「台」和「臺」都找得到），選過的會記在瀏覽器，下次直接顯示。
- 沒選過時預設顯示臺北中山站，並標示「預設測站」。我不用定位，也不宣稱「最近的測站」，因為環境部的資料沒有提供站型與涵蓋範圍。
- 版面比例參考了 IQAir 臺北城市頁：置中的單欄、搜尋列、麵包屑、大標題、兩張等寬的平面卡片、同寬的地圖，再接排行表。

## 色彩與可讀性

- AQI 六級沿用環境部的色相（綠、黃、橘、紅、紫、褐紅），色塊上的文字都做過對比計算，至少 4.5:1。
- 顏色不是唯一的資訊：數字和類別名稱一定一起出現，色階條上有目前位置，地圖上的標記本身就是數字。
- 地圖上標記重疊時，會依「所選測站、資料較新、AQI 較高」的順序保留數字，其餘縮成小圓點，放大後再展開。
- 字級只用 12／14／16／18／22／28／36／48／64／96 這組階梯，內文 16px，次要說明 14px；12px 只用在地圖標記、色階刻度和圖磚授權。
- 預設淺色，可手動切換深色，選擇會記在瀏覽器。

## 資料時間要誠實，但不要嚇人

環境部每小時發布一次，而 GitHub Pages 的排程實際上常常 3–4 小時才跑一次，所以資料「有點舊」是常態。我把時效分成三段，從資料自己的發布時間算起，在瀏覽器端用現在的時間計算：

| 狀態 | 資料時間 | 呈現 |
|---|---|---|
| 即時 | 90 分鐘內 | 中性色的「資料時間 HH:MM · N 分鐘前」 |
| 稍舊 | 6 小時內 | 同一行改成琥珀色，AQI 顏色和建議不變 |
| 過舊 | 24 小時內 | 琥珀色，另加一句「最新數據請見環境部空氣品質監測網」 |
| 無法使用 | 超過 24 小時 | AQI 數字保留但改成中性色，不提供活動建議 |

網路或資料有問題時，會顯示這個瀏覽器上次成功載入的資料，只有一筆都沒有時才出現錯誤卡片。

## 資料與金鑰

- 瀏覽器只讀同站的靜態 `data/aqi-latest.json`，不接觸環境部 API。
- 這個 JSON 由 GitHub Actions 在部署時產生：用 repository secret 呼叫 API，經 `scripts/aqi-cache-contract.mjs` 檢查（至少 80 站、22 個縣市、AQI 為 0–500 的整數、時間不超前也不超過 3 小時等）通過後才打包部署，不會寫回 repo。
- 任何一步失敗都不部署，線上維持上一版。部署前還會掃描 build 產物，確認沒有任何憑證字串。

## 圖示與品牌標記

- 圖示全部使用 Lucide，線寬 1.75、圓頭線端與轉角，尺寸只有 16、20、24。
- 品牌標記是圓角方形（圓角為邊長的 22%）填 teal `#29aea0`，中間是白色的 Lucide `wind`（佔 58%，線寬 2）。同一個 `public/brand/mark.svg` 用在頁首、`favicon.svg`，並產生 `apple-touch-icon.png`。
